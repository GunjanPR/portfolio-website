# Gunjan Rajgure - AI Systems Portfolio

A responsive, resume-led portfolio built for GitHub Pages. It presents Gunjan's
professional experience, the deployed eMIND Visuals product, PhenoZebra research,
measured AI systems projects, broader data science work, education, and technical
toolkit. No build step or package installation is required.

## Preview

Open `index.html` directly in a browser.

## Personalize before publishing

- Keep the downloadable resume in `assets/Gunjan-Rajgure-Resume.pdf` aligned with the master resume.
- Keep the public eMIND poster and live application link aligned with the latest conference release.
- The Systems section shows the four portfolio projects (LLM gateway, healthcare RAG,
  MLOps, forecasting). Each number comes from that repository's README,
  `docs/resume_bullets.md` or `docs/benchmarks/`, with its baseline and caveat.
- Repositories that are still private show "code on request". When one goes public,
  replace its `private-repo` mailto link with the GitHub URL.
- Update measured outcomes only when the source repository's evidence changes.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Push the contents of this folder to the repository's default branch.
3. In the repository, open **Settings > Pages**.
4. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

The `.nojekyll` file keeps GitHub Pages from applying Jekyll processing.
